## 1. Motivation

High-dimensional dependence modelling faces two competing demands: **flexibility** (different variable pairs can exhibit different dependence patterns — tail dependence, asymmetry, strength) and **parsimony** (models should not have too many parameters relative to the data). The main prior approaches fall short:

- **Gaussian/Student-t copulas**: easy to estimate, but symmetric, and in the Gaussian case have zero tail dependence. The $t$ copula forces equal upper and lower tail dependence.
- **Archimedean copulas** (Clayton, Gumbel, Frank): generated by a single parameter $\theta$, implying the *same* bivariate dependence for every pair — too rigid for any real multivariate data set.
- **Factor copulas** (Oh & Patton 2012): elegant latent-factor construction; scalable to very high dimensions; analytical tail-dependence via EVT; but all pairwise copulas share a common latent structure and all pairs are "equidependent" unless a flexible-weights extension is used.
- **Pair Copula Constructions / Vine copulas** (Joe 1996; Bedford & Cooke 2001, 2002; Aas et al. 2009): every pair of variables (possibly conditioned on others) gets its own bivariate copula, from *any* bivariate family. Maximum flexibility; $n(n-1)/2$ pair copulas total. The price is a more complex structure (which pair-copulas to use in which tree) and the need for structure selection.

## 2. The Bivariate Copula Building Block

A **bivariate copula** $C:[0,1]^2 \to [0,1]$ captures the dependence between two uniform random variables $U_1 = F_1(X_1)$, $U_2 = F_2(X_2)$. Sklar's theorem says any bivariate density can be written as:
$$
f(x_1, x_2) = f_1(x_1) \cdot f_2(x_2) \cdot c_{12}(F_1(x_1), F_2(x_2))
$$
where $c_{12}(u,v) = \partial^2 C_{12}(u,v)/\partial u\,\partial v$ is the copula density.

**Standard bivariate copula families used in vine copulas:**

| Family | Tail dependence | Skewness | Parameters |
|--------|----------------|----------|-----------|
| Gaussian | None (τ^L = τ^U = 0) | Symmetric | ρ ∈ (−1,1) |
| Student-t | Equal upper/lower | Symmetric | ρ, ν |
| Clayton | Lower tail only | Asymmetric | θ > 0 |
| Gumbel | Upper tail only | Asymmetric | θ ≥ 1 |
| Frank | None | Symmetric | θ ∈ ℝ\{0} |
| Joe | Upper tail | Asymmetric | θ ≥ 1 |
| BB1 (Clayton-Gumbel) | Both tails | Asymmetric | θ, δ |
| BB7 (Joe-Clayton) | Both tails | Asymmetric | θ, δ |

Rotated versions (90°, 180°, 270°) allow lower-tail-only versions of Gumbel and Joe.

## 3. Pair Copula Construction (PCC): The Core Idea

**Joe (1996)** observed that any $n$-variate density can be factored as a product of bivariate copula densities applied to conditional distribution functions, with each factor depending on at most two conditioning variables. However, the representation is not unique — there are many valid factorisations.

For $n = 3$, two natural decompositions of $f(x_1, x_2, x_3)$:

**Decomposition A (conditioning on $x_2$):**
$$
f(x_1,x_2,x_3) = c_{12}(F_1(x_1),F_2(x_2)) \cdot c_{23}(F_2(x_2),F_3(x_3)) \cdot c_{13|2}(F_{1|2}(x_1|x_2), F_{3|2}(x_3|x_2)) \cdot f_1(x_1)f_2(x_2)f_3(x_3)
$$

**Decomposition B (conditioning on $x_1$):**
$$
f(x_1,x_2,x_3) = c_{12}(F_1(x_1),F_2(x_2)) \cdot c_{13}(F_1(x_1),F_3(x_3)) \cdot c_{23|1}(F_{2|1}(x_2|x_1), F_{3|1}(x_3|x_1)) \cdot f_1(x_1)f_2(x_2)f_3(x_3)
$$

In both cases, the three bivariate copulas $c_{12}$, $c_{23}$, $c_{13|2}$ (or $c_{12}$, $c_{13}$, $c_{23|1}$) each describe a different aspect of the dependence. This idea generalises to $n$ dimensions, requiring $n(n-1)/2$ pair copulas in a specific hierarchical structure — the vine.

**Key computational primitive: the h-function**

For sequential density evaluation and simulation, define the *conditional distribution function*:
$$
h(u|v; \theta) \equiv F(U_1 \le u \mid U_2 = v) = \frac{\partial C(u,v;\theta)}{\partial v}
$$
For common families:
- **Gaussian copula** with parameter ρ: $h(u|v;\rho) = \Phi\!\left(\frac{\Phi^{-1}(u) - \rho\,\Phi^{-1}(v)}{\sqrt{1-\rho^2}}\right)$
- **Clayton copula**: $h(u|v;\theta) = v^{-\theta-1}(u^{-\theta}+v^{-\theta}-1)^{-1-1/\theta}$
- **Gumbel copula**: $h(u|v;\theta) = C(u,v;\theta) \cdot \frac{1}{v}(-\ln v)^{\theta-1}[(-\ln u)^\theta + (-\ln v)^\theta]^{1/\theta - 1}$

The inverse $h^{-1}(w|v;\theta)$ is used for simulation.

## 4. Regular Vine (R-Vine): The Graph-Theoretic Framework

**Bedford & Cooke (2002)** formalized the graphical structure underlying all valid PCCs.

**Definition — Regular vine on $n$ variables:**  
A *vine* $\mathcal{V}$ on $n$ variables is a nested set of trees $\{T_1, T_2, \ldots, T_{n-1}\}$ where:
1. $T_1 = (N_1, E_1)$ is a connected tree with nodes $N_1 = \{1,\ldots,n\}$ and edges $E_1$.
2. For $k = 2, \ldots, n-1$: $T_k = (N_k, E_k)$ is a connected tree where $N_k = E_{k-1}$ (the *edges* of $T_{k-1}$ become the *nodes* of $T_k$).
3. **Proximity condition** (makes it *regular*): if two nodes $a = \{a_1, a_2\}$ and $b = \{b_1, b_2\}$ in $T_k$ are connected by an edge, then $|a \cup b| = k+1$ (exactly one index from $a$ and $b$ are in common — the *conditioning set*).

**The edge label convention**: each edge in $T_k$ corresponds to a pair copula $c_{j(e),k(e)|D(e)}$ where:
- $j(e)$ and $k(e)$ are the two *conditioned* variables (the unconditioned part of the edge's end nodes' symmetric difference),
- $D(e)$ is the *conditioning set* (the intersection of the two end nodes).

**The joint density in terms of an R-vine:**
$$
f(x_1,\ldots,x_n) = \prod_{k=1}^{n} f_k(x_k) \cdot \prod_{k=1}^{n-1} \prod_{e \in E_k} c_{j(e),k(e)|D(e)}\!\left(F(x_{j(e)}|x_{D(e)}),\, F(x_{k(e)}|x_{D(e)})\right)
$$
Under the **simplifying assumption** (the conditional copulas do not depend on the conditioning values $\mathbf{x}_{D(e)}$, only on the conditioning set structure $D(e)$), this product is exact and all $n(n-1)/2$ pair copulas are independent of the conditioning values.

## 5. C-Vine (Canonical Vine)

**Definition:** A *C-vine* is an R-vine where *each tree $T_k$ is a star*: one root node (the $k$-th root node $p_k$) is connected to all others. The root node in $T_1$ is variable $p_1$; in $T_2$, the root is the edge $(p_1, p_2)$ where $p_2$ is the second root variable.

**Tree structure for $n=4$:**
- $T_1$: star with root 1 → edges (1,2), (1,3), (1,4)
- $T_2$: star with root (1,2) → edges (1,3|2), (1,4|2) ... but root is still variable 1 by convention
  - Actually: star rooted at node 1 in T_2 which has edges: (2,3|1), (2,4|1)
- $T_3$: one edge: (3,4|1,2)

The $n(n-1)/2$ pair copulas in a C-vine (with root order $p_1,\ldots,p_n$):
$$
\text{C-vine density} = \prod_{k=1}^n f_k(x_k) \prod_{j=1}^{n-1} \prod_{i=1}^{n-j} c_{j,j+i|1,\ldots,j-1}(F_{j|1,\ldots,j-1}(x_j|\mathbf{x}_{1:j-1}),\, F_{j+i|1,\ldots,j-1}(x_{j+i}|\mathbf{x}_{1:j-1}))
$$

**Simulation from a C-vine (sequential)**:
1. Draw $w_1,\ldots,w_n \sim \text{Unif}(0,1)$.
2. $u_1 = w_1$.
3. $u_2 = h^{-1}(w_2 | u_1; \theta_{12})$.
4. $u_3 = h^{-1}(h^{-1}(w_3 | u_1; \theta_{13}) | h(u_2|u_1;\theta_{12}); \theta_{23|1})$.
5. Continue similarly for $u_4, \ldots, u_n$ building up conditional quantities.

**Best use case:** When one or a few variables "drive" all others — analogous to a factor model. For equity returns, the market index or a specific sector driving all stock returns.

## 6. D-Vine (Drawable Vine)

**Definition:** A *D-vine* is an R-vine where *each tree $T_k$ is a path* (no node has degree more than 2).

**Tree structure for $n=4$:**
- $T_1$: path 1–2–3–4 → edges (1,2), (2,3), (3,4)
- $T_2$: path (1,2)–(2,3)–(3,4) → edges (1,3|2), (2,4|3)
- $T_3$: one edge (1,4|2,3)

The pair copulas in order: $c_{12}$, $c_{23}$, $c_{34}$, $c_{13|2}$, $c_{24|3}$, $c_{14|23}$.

**Density for a D-vine:**
$$
f(x_1,\ldots,x_n) = \prod_{k=1}^n f_k(x_k) \prod_{k=1}^{n-1} \prod_{i=1}^{n-k} c_{i,i+k|i+1,\ldots,i+k-1}(F_{i|i+1,\ldots,i+k-1},\, F_{i+k|i+1,\ldots,i+k-1})
$$

**Simulation from a D-vine** requires a more complex recursive application of h-functions, proceeding from edge to edge.

**Best use case:** When variables have a natural ordering — financial time series lags, spatial locations along a transect, ordinal survey questions. The pair copulas near the "diagonal" of the path ($(i,i+1)$ edges) model adjacent-lag dependencies; higher-order trees capture longer-range conditional dependencies.

## 7. Comparison: Vine vs Factor Copulas

| Feature | Vine Copulas | Factor Copulas (Oh & Patton) |
|---------|-------------|------------------------------|
| Parameter count | $n(n-1)/2$ pair copulas | A few latent-factor parameters |
| Pairwise flexibility | Any bivariate family per pair | Same family for all pairs (from factor structure) |
| Dimension | Best for $n \le 20$–30 | Scales to $n = 100+$ |
| Structure | Hierarchical trees | Latent linear factor |
| Tail dependence | Pair-specific (each pair can have its own) | Analytical via EVT; same family |
| Estimation | Sequential ML (fast), full ML (slow) | SMM (no closed-form density) |
| Interpretation | Explicit pair-level dependence | Market/systemic risk factor interpretation |
| Curse of dimensionality | Yes — structure selection NP-hard | No — parsimony by design |
| Software | VineCopula (R), pyvinecopulib | Custom (SMM code) |

**Practical guidance:**
- 2–20 variables with heterogeneous pairwise patterns → vine copula
- 20–100+ variables with shared systemic factor → factor copula
- Financial returns data: both approaches are used; vine copulas for sector-level portfolios, factor copulas for index-level

## 8. Estimation Methods

**8.1 Inference Functions for Margins (IFM)**
1. Estimate each marginal $F_k$ separately (parametric or empirical CDF / probability integral transform).
2. Convert observed data to pseudo-observations $\hat{u}_{t,k} = \hat{F}_k(x_{t,k})$.
3. Estimate vine copula parameters $\boldsymbol{\theta}$ by maximizing the vine log-likelihood:
   $$
   \hat{\boldsymbol{\theta}}_{\text{IFM}} = \arg\max_{\boldsymbol{\theta}} \sum_{t=1}^T \sum_{e \in \mathcal{V}} \log c_{j(e),k(e)|D(e)}(\hat{F}_{j|D}(x_{t,j}|\mathbf{x}_{t,D}), \hat{F}_{k|D}(x_{t,k}|\mathbf{x}_{t,D}); \theta_e)
   $$

**8.2 Sequential (Tree-by-Tree) ML**
Aas et al. (2009) propose a computationally efficient sequential procedure:
1. Fit all pair copulas in $T_1$ by MLE. Get $\hat{\theta}_e$ for $e \in E_1$.
2. Use these estimates and the h-function to transform pseudo-observations to the conditioning sets for $T_2$: $\hat{u}_{j|k} = h(\hat{u}_j | \hat{u}_k; \hat{\theta}_{jk})$.
3. Fit all pair copulas in $T_2$ by MLE on the transformed observations.
4. Continue tree by tree.

This is a fast but inefficient estimator (ignores cross-tree parameter uncertainty). It yields consistent, asymptotically normal estimates under mild regularity conditions.

**8.3 Full MLE**
Optimize all pair-copula parameters jointly. Computationally expensive but efficient. For $n=10$ with a 5-tree vine, this means 45 parameters simultaneously.

## 9. Model Selection

**9.1 Vine structure selection (which R-vine?)**
- For C-vines: choose the root variable (e.g., the one with highest average pairwise dependence, or domain knowledge).
- For D-vines: choose the path ordering.
- For general R-vines: **Dissmann et al. (2013)** algorithm:
  1. Build maximum spanning tree $T_1$ by maximizing total pairwise dependence (|Kendall's $\tau$| on each edge).
  2. For $T_2$ on the proxy-data (h-function outputs from $T_1$), build another maximum spanning tree satisfying the proximity condition.
  3. Continue to $T_{n-1}$.

**9.2 Pair copula family selection**
For each edge, select the bivariate copula family by AIC or BIC from a candidate set (Gaussian, $t$, Clayton, Gumbel, Frank, Joe, and rotations). The $t$ copula is a strong default for financial data.

**9.3 Truncation**
For dimensions $n \ge 10$, set all pair copulas in trees $T_k$ for $k > K_0$ to the independence copula. Often $K_0 = 2$ or $3$ suffices — conditional dependencies at high tree levels are typically weak. This reduces the effective number of parameters dramatically.

## 10. Software

**R — VineCopula package (Schepsmeier et al.):**
```r
library(VineCopula)
# Fit truncated R-vine to data matrix U (n × d, pseudo-observations in [0,1])
RVM <- RVineStructureSelect(U, familyset = c(1, 2, 3, 4, 5), trunclevel = 3)
# Simulate 1000 samples
sim <- RVineSim(1000, RVM)
# Log-likelihood
RVineLogLik(U, RVM)
```

**Python — pyvinecopulib:**
```python
import pyvinecopulib as pv
import numpy as np
# Fit vine copula (automatic structure + family selection)
cop = pv.Vinecop(data=U)  # U is n×d array of pseudo-observations
# Simulate
samples = cop.simulate(n=1000)
# Loglik
cop.loglik(U)
```

**Key parameters:** `family_set` to restrict candidate copula families; `trunc_lvl` for truncation; `select_trunc_lvl=True` for automatic truncation selection.
