**Paper:** "Selecting and estimating regular vine copulae and application to financial returns"

## Abstract Summary

Derives the density of an arbitrary regular vine (R-vine) specification, extending
beyond the canonical C-vine and D-vine special cases. Proposes a sequential, tree-
by-tree structure selection algorithm: at each tree level, select the spanning tree
that maximizes the sum of pairwise absolute Kendall's τ values. Implements the
algorithm in the VineCopula R package. Applied to financial data, shows the
sequential selection recovers strong dependence structures.

## Key Contributions

1. General R-vine density formula (beyond C-vine and D-vine)
2. Sequential structure selection via maximum-spanning-tree algorithm
3. Sequential parametric copula family selection per pair
4. Implementation in VineCopula R package
