# Conditional Independence Testing in Causal Discovery

> [!summary]
> The **PC algorithm** and all constraint-based discovery methods hinge on repeated
> **conditional independence (CI) tests**: statistical tests of whether $X \perp\!\!\!\perp Y \mid S$
> for various triplets $(X, Y, S)$. The choice of CI test determines which data types and
> distributional assumptions are handled, and directly controls the algorithm's **type I error**
> (false edge removal) and **type II error** (missed edge removal). For continuous Gaussian data
> the **Fisher's Z test** (partial correlation) is standard; discrete data use the **$G^2$ test**;
> non-parametric and non-linear settings require kernel-based or distance-based tests.

## Overview

A CI test for $X \perp\!\!\!\perp Y \mid S = s_1, \ldots, s_k$ answers: given observations of $(X, Y, S_1, \ldots, S_k)$,
is there statistical evidence that $X$ and $Y$ are dependent after conditioning on $S$?
Each test produces a p-value; the null hypothesis is independence. The significance level
$\alpha$ is the key tuning parameter in PC: a smaller $\alpha$ makes the test more conservative
(fewer edge removals, denser graph), while a larger $\alpha$ gives a sparser graph but more
false removals.

The **size of the conditioning set** is the critical challenge: statistical power falls sharply
as $|S| = k$ grows, because we are effectively slicing the data into finer and finer cells.
This is why PC processes conditioning sets in order of size $k = 0, 1, 2, \ldots$.

## Main Content

### Fisher's Z Test (Gaussian Data, Linear Relations)

> [!definition] Definition: Partial Correlation CI Test
> For continuous Gaussian variables, conditional independence $X \perp\!\!\!\perp Y \mid S$ is
> equivalent to zero **partial correlation** $\rho_{XY \cdot S} = 0$.
>
> **Test statistic (Fisher's Z transform):**
> $$z = \frac{1}{2} \ln\!\left(\frac{1 + \hat{\rho}_{XY\cdot S}}{1 - \hat{\rho}_{XY\cdot S}}\right)$$
> which is approximately $\mathcal{N}(0, 1/(n - |S| - 3))$ under $H_0: \rho_{XY\cdot S} = 0$.
>
> **Computation:** $\hat{\rho}_{XY\cdot S}$ is computed from the inverse of the sample
> covariance sub-matrix involving $(X, Y, S)$, using the Schur complement:
> $$\hat{\rho}_{XY\cdot S} = -\frac{[\Sigma^{-1}_{[X,Y,S]}]_{XY}}{\sqrt{[\Sigma^{-1}_{[X,Y,S]}]_{XX}[\Sigma^{-1}_{[X,Y,S]}]_{YY}}}$$
>
> **Reject independence** if $|z| > z_{\alpha/2}$ (two-sided test at level $\alpha$).
>
> **Cost:** $O(k^3)$ for the matrix inverse; negligible for small $k$.
> ^def-fisher-z

> [!note] When Fisher's Z is appropriate
> Fisher's Z is exact for multivariate Gaussian data and asymptotically valid for any data
> generated by a **linear SEM** (since the model-implied conditional distributions are linear
> and Gaussian). For non-Gaussian or non-linear relations, it can still detect linear
> conditional dependence, but may miss non-linear relationships.

### G-Test / Chi-Squared Test (Discrete Data)

> [!definition] Definition: $G^2$ Test for Discrete Data
> For discrete variables with state spaces $\mathcal{X}, \mathcal{Y}$, the conditional
> independence $X \perp\!\!\!\perp Y \mid S$ is tested via the **$G^2$ likelihood-ratio statistic**:
> $$G^2 = 2 \sum_{x, y, s} n_{xys} \ln\!\frac{n_{xys} \cdot n_s}{n_{xs} \cdot n_{ys}}$$
> where $n_{xys}$ are observed cell counts and $n_s = \sum_{x,y} n_{xys}$.
>
> Under $H_0$, $G^2 \xrightarrow{d} \chi^2$ with $(|\mathcal{X}|-1)(|\mathcal{Y}|-1)\prod_{i}|\mathcal{S}_i|$
> degrees of freedom.
>
> **Key limitation:** As the state spaces and $|S|$ grow, the contingency table becomes
> *sparse* — many cells have $n_{xys} = 0$ — violating the asymptotic approximation and
> destroying power. This is the finite-sample fragility Lee et al. (2025) address.
> ^def-g2-test

### Kernel-Based CI Tests (Non-Parametric)

For non-linear, non-Gaussian settings, kernel-based tests extend the parametric approaches:

| Test | Key idea | Software |
|-----|---------|---------|
| **KCI** (Kernel CI, Zhang et al., 2012) | Hilbert-Schmidt independence criterion in feature space; exact for non-linear, non-Gaussian | `causal-learn`, `kcipy` |
| **RCIT** (Randomized CI Test, Strobl et al., 2019) | Random Fourier features for scalable KCI | `RCIT` R package |
| **CMIknn** (CMI via k-NN, Runge, 2018) | Nonparametric CMI estimation via nearest-neighbor entropy | `tigramite` |
| **FastKCI** | Approximation of KCI for large $n$ | Faster but less exact |

> [!note] The faithfulness—power trade-off
> Non-parametric CI tests have more power to detect non-linear dependencies, but are more
> susceptible to spurious rejections (higher Type I error). For large conditioning sets,
> all CI tests lose power — the curse of dimensionality is inescapable. This motivates the
> **C-PC algorithm** (Lee et al., 2025): restrict CI tests to a carefully chosen collection
> of conditioning sets $\mathcal{C}$ to avoid tests with near-deterministic conditioning
> variables that destroy power.

### Multiple Testing and Error Control

CI tests in PC are performed sequentially for correlated hypothesis pairs, creating a
multiple testing problem. Standard approaches:

| Strategy | Effect |
|---------|--------|
| Fixed $\alpha$ (most common) | No correction; skeleton error accumulates with $d$ |
| Bonferroni-corrected $\alpha' = \alpha/\binom{d}{2}$ | Conservative; over-retains edges |
| BH procedure (Benjamini-Hochberg) | FDR control; used in some PC-stable variants |

In practice, $\alpha = 0.01$ or $0.05$ is used without correction, and the result is
validated via domain knowledge or intervention experiments.

### The Effect of Sample Size

> [!example] Sample Size and CI Test Reliability
> For the Fisher's Z test, the effective sample size for a CI test with conditioning set
> $S$ of size $k$ is approximately $n - k - 3$. With $n = 500$ and $k = 5$, the effective
> $n$ is 492 — still reasonable. But for $k = 15$ (dense graph, many adjacencies),
> the test is essentially operating on $n = 482$ observations *after partitioning* the
> data — and for discrete data, each partition cell gets only $500 / |\text{cells}|$ observations.
>
> This is why structure learning is reliable in the Gaussian / linear case for moderate
> $n$ and $k$, but fails badly for discrete data with large state spaces or high $k$.
