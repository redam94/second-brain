# Citation: Kalisch & Bühlmann (2007)

**Authors:** Markus Kalisch, Peter Bühlmann
**Title:** Estimating High-Dimensional Directed Acyclic Graphs with the PC-Algorithm
**Journal:** Journal of Machine Learning Research, Vol. 8, pp. 613–636, 2007
**arXiv:** math/0510436 [math.ST] (submitted 20 Oct 2005)
**JMLR URL:** https://jmlr.org/papers/v8/kalisch07a.html

## Abstract (from search results)

Studies the PC algorithm for estimating the skeleton and equivalence class of a high-dimensional
DAG under Gaussian assumptions. Establishes uniform consistency for sparse graphs where the
node count $d$ can grow with sample size $n$ as fast as $O(n^a)$ for any $0 < a < \infty$.

## Key Results

- Uniform consistency of PC algorithm skeleton in high dimensions
- Conditions: Gaussian SEM, sparse graph (bounded max degree), faithful distribution
- Consistency of CPDAG identification
- High-dimensional regime: d = O(n^a) for any 0 < a < ∞
