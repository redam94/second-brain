# Reference: Kalisch & Bühlmann (2007)

**Title:** Estimating High-Dimensional Directed Acyclic Graphs with the PC-Algorithm

**Authors:** Markus Kalisch, Peter Bühlmann

**Journal:** Journal of Machine Learning Research, Volume 8, pp. 613–636, 2007

**arXiv preprint:** https://arxiv.org/abs/math/0510436

**Abstract:** The PC-algorithm (Spirtes et al., 2000) estimates the skeleton
and equivalence class of a directed acyclic graph (DAG) from observational data.
This paper proves consistency of the algorithm for very high-dimensional sparse DAGs
where the number of nodes p is allowed to grow with sample size n as fast as O(n^a)
for any 0 < a < ∞, given a consistent conditional independence test.
The sparse faithfulness assumption is introduced and shown sufficient for consistency.

**Key contributions:**
1. High-dimensional consistency proof for PC algorithm under sparsity + faithfulness
2. Sparse faithfulness assumption (weaker than standard faithfulness for high-dimensional settings)
3. Calibration study using partial correlations and Fisher's z-test as the CI test
4. Connection to Gaussian graphical models via Markov property
